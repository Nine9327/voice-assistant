性格预设 —

同一句回答，换个性格就是另一种味道。选一张卡片，点右下角「保存并应用」； 也可以直接对它说「换成傲娇」，当场就换。

所有性格都会遵守这一条，用来微调称呼、口头禅、回答长度这类细节。

MCP 工具 —

MCP（Model Context Protocol）把文件、数据库、浏览器这类外部能力接到模型手上， 什么时候调用由模型自己判断 —— 你只管说「看看我桌面上那个文档」。

关掉后不启动任何服务器进程。开着时每轮对话会多做一次工具判定，回答通常慢零点几秒； 模型不支持工具调用会自动退回普通对话，不会报错。

语音识别服务 —

决定「怎么听懂你」。本地快且不花钱，网络接口不吃显卡。

网络识别复用「大模型服务」里填的接口地址和 API Key，无需重复填写。改完保存会自动重载识别服务。

语音合成服务 —

决定「用什么声音说」。在线音质自然，离线断网也能用。

语速与音量沿用上面的设置。离线引擎音质偏机械，但延迟极低、不花流量。

说一句提示词就能开口，不用按空格。改完保存即刻生效，无需重启。

联网搜索 —

问天气、新闻、股价这类「此刻才成立」的事，先去网上查一段再回答，而不是让本地模型硬编。

按问题判断：出现「今天/最新/股价/天气/新闻」这类时效词，或者「帮我查一下」这种明确要求时才查， 闲聊不查。「现在几点」「今天周几」由本地时间直接回答，不会浪费一次搜索。
必应免 Key、国内可直连，够用就别换。Tavily 和博查的摘要更贴合大模型，但都要自己申请 Key。
